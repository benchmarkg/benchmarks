Semantic Scholar Academic Graph API responses -- test fixtures, no licence granted by this project

The files under tests/fixtures/citations/semantic-scholar/ are responses from the Semantic Scholar
Academic Graph API (https://api.semanticscholar.org/graph/v1/paper/...), captured on 2026-10-04 by
tests/fixtures/citations/capture.py and kept byte for byte, with their status and Content-Type, so
the citation cross-check (ingest/adapters/semantic_scholar.py) can be tested offline. Each holds one
paper's ids, title, venue, year, citation count and open-access PDF link.

This project does not own them and grants no licence to them. They are Semantic Scholar data, from
the Allen Institute for AI, served under the Semantic Scholar API License Agreement
(https://www.semanticscholar.org/product/api/license), which requires attribution.

They are retained only as test fixtures. They are not part of the published dataset, are not
